## 🌟 Overview & Features
A high-performance, multi-page web application engineered for **Jena Welding Company**:
- **Full-Screen Live Welding Video Hero:** Cinematic video background with high-contrast industrial typography and direct WhatsApp quote triggers.
- **Clean Industrial Theme:** Inspired by modern international metalwork websites (white body, industrial navy header utility bar, safety orange CTAs).
- **6 Core Fabrication Departments:** Interactive department cards with drill-down views into all sub-categories and technical specifications.
- **19-Project Portfolio Gallery:** High-definition real installation showcase with universal fullscreen lightbox zoom and WhatsApp inquiry actions.
- **Founder Spotlight:** Highlighting **PRASHANJIT JENA** (Founder & Managing Director) with 25+ years of craftsmanship in Sakhigopal, Puri.
- **Pan-India Dispatch & Odisha Coverage:** Transparent logistics tracking from coastal Odisha to all states of India.

---

## 🚀 Key Pages & Real Routing (`HashRouter`)
- **Home (`/#/`):** Full-screen video hero, UDYAM verified badging, 6-department overview, founder profile, featured projects, pan-India logistics banner.
- **Products & Services (`/#/services`):** 6 main departments with full drill-down sub-category view, technical specifications, and steel corrosion resistance matrix.
- **Project Gallery (`/#/gallery`):** 19 real-world project installations with universal fullscreen lightbox viewer.
- **Contact & Inquiry (`/#/contact`):** Full contact hubs, interactive quote request form, and exact Sakhigopal Google Maps location pin.

## 🛠️ Technology Stack
- **Framework:** React 18 + Vite 5
- **Routing:** React Router DOM v6 (`HashRouter` for zero-error static hosting on GitHub Pages)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Celebration Effects:** Canvas Confetti
